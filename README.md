# Forno — піца, що має характер

Демо-сайт італійської піцерії: адаптивна головна сторінка, англійська мова за
замовчуванням із перемикачем на українську, меню з фільтрами й інгредієнтами,
кошик, фіксовані акційні комбо-набори й форма демонстраційного замовлення.
Вибір мови зберігається у браузері.
Ціни відображаються в доларах англійською та у гривнях українською; USD-ціни
для демо розраховуються за фіксованим курсом 40 ₴ за $1.

## Запуск локально

Потрібен Node.js 18 або новіший. Встановлювати залежності не потрібно.

```bash
npm start
```

Відкрийте [http://localhost:3000](http://localhost:3000). Щоб зупинити сервер,
натисніть `Ctrl+C` у терміналі. За потреби порт можна змінити, задавши змінну
середовища `PORT`.

Замовлення в цій версії демонстраційні: форма показує підтвердження, але не
надсилає дані до піцерії.
